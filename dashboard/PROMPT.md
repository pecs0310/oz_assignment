# 재현용 프롬프트: 상급종합병원 영상검사 수요 질환군 대시보드

## 0. 준비
- 데이터: `kr_claims.xlsx`(강의 백업 시트). 사용 시트: claim, institution, sick_master, code_table
- 결과물: `dashboard/index.html` 한 장(데이터 내장, Chart.js CDN) + 집계 스크립트 `dashboard/build_data.py`

## 1. 기획
```
이 페이지는 [상급종합병원 영상의학과장]이 [분기별 장비·판독 인력 계획 회의 전]에
[영상검사 수요가 큰 환자군의 규모와 진료비 비중을 확인하기 위해] 본다.
```
- 처음엔 수업 예시(병원 경영기획팀장)로 만들었다가, 의료영상 AI 쪽 관심에 맞춰 영상의학과장으로 바꿨다.
- 데이터에 영상검사 행위 코드가 없어서, CT·MRI가 진단·추적에 핵심인 질환군을 영상 수요의 대리 지표로 정했다.
  - 뇌혈관질환 I60–I69 / 악성신생물 C / 손상 S / 폐렴 J12–J18 / 근골격계 M / 나머지는 기타

## 2. 데이터 집계
```
kr_claims.xlsx의 모든 시트를 글자(str)로 읽어줘. 031, 01처럼 앞자리 0인 코드가 바뀌면 안 돼.
claim에 yid로 institution을 붙여서 cl_cd가 '01'(상급종합병원)인 명세서만 남겨줘.
main_sick 코드로 위 다섯 질환군 + 기타로 나누는 함수를 만들고, 아래를 data.json으로 저장하는 build_data.py를 만들어줘.
- 상급종합병원 KPI: 명세서 수, 진료비 합계, 영상 수요 질환군의 명세서 비중(%)과 진료비 비중(%)
- 질환군별: 명세서 수, 입원 수(fom_tp_cd '021'), 명세서 비중, 진료비 비중, 건당 진료비
- 상급종합병원 진료비 합계 Top 10 상병 (sick_master의 krnm 붙이기, 질환군 표시)
- 전체 종별 건당 진료비 (code_table의 '종별코드'로 이름 붙이기, 의원→병원→종합병원→상급종합병원 순)
```

## 3. 대시보드 HTML
```
data.json을 HTML 안에 넣어서 index.html 한 장으로 만들어줘. Chart.js는 CDN으로.
- 맨 위: 제목, 질문 한 줄, 기획 한 줄 문장
- KPI 카드 4개
- 2열: 질환군별 명세서 비중 vs 진료비 비중(가로 묶음 막대, 범례) / 진료비 Top10 상병(영상 질환군은 파란색, 기타는 회색)
- 전체 폭: 종별 건당 진료비(상급종합병원만 강조)
- 차트마다 아래에 "왜 이 차트를 넣었는지" 한 줄
- '숫자로 본 것'(데이터에서 계산), '가정과 한계', 맨 아래 "인사이트:"는 비워두고 내가 직접 쓴다
- 다크 모드, 모바일 1열, 호버 툴팁, '표로 보기' 토글
```

## 4. 숫자로 본 것
- 영상 수요 질환군은 상급종합병원 명세서의 35.2%지만 진료비의 63.6%를 차지한다.
- 뇌혈관질환은 명세서 1.0%(20건, 전부 입원)인데 진료비는 24.1%를 차지한다.
- 근골격계는 명세서 26.2%로 가장 많지만 진료비는 13.4%에 그친다.
- 진료비 1위 상병은 파열되지 않은 대뇌동맥류(I671)로, 환자 4명에 1.7억 원이다.
